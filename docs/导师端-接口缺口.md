### 1.1 预约 / 过程材料

- 前端不再调用通用 `/files/{id}/preview|download`（需要 `file:list`）。
- `preview` 走 `FilePreview`（图片 / PDF 内嵌），`download` 走带鉴权的 blob 下载。
- 仍保留「移除」按钮，仅对本人上传的过程材料且预约状态允许时显示。

### 1.2 成果佐证

- 成果列表对有佐证的记录显示「佐证 / 下载」；无佐证不显示按钮。
- 预览与下载都按成果 id 走专用路由，不再暴露 `proofFileId` 给通用文件接口。

### 1.3 指导记录与台账

- `/mentor/records` 直接使用 `GET /mentor/records`，不再做「预约列表 + 逐条查记录」的 N+1。
- 导出使用 `GET /mentor/records/export`，文件名取 `Content-Disposition`。
- 统计页保留聚合统计导出（`/stats/guidance/export`），并新增「指导记录台账」入口到 `/mentor/records`。

### 1.4 建档人员类型

- `user.mentorType === 'internal'` → 建档表单隐藏合作单位 / 社会任职；
- `external` → 显示；
- `null` → 显示并提示保存后按人员类型校正。

### 1.5 草稿佐证材料

- 建档 / 已退回状态显示「草稿佐证材料」上传区；
- 上传先落无归属 `SysFile`，元数据保存在 `sessionStorage`（按用户区分），刷新页面不丢列表；
- 提交入驻申请成功后，逐条调用 `POST /mentor-applications/{id}/materials` 挂接；
- 挂接失败的条目提示用户到申请详情重新上传；
- 注意：提交申请本身不会自动绑定草稿文件，绑定发生在提交成功后的前端认领调用。

### 1.6 申请详情

- `GET /mentor-applications/{id}` 已修复，前端直接使用详情响应展示快照、审核记录、撤回与材料。

## 3. 非接口问题：teacher 读档案 403

`GET /mentor/profile` 已接受 `personType ∈ {internalMentor, externalMentor, teacher}`。
手工通过 `POST /users/account` 创建的 teacher 账号没有对应 `SyncPerson`，因此仍会 403：

- 处理方式：确认源系统存在该教师 → 由管理员在平台「系统管理 → 定时同步」触发一次统一认证同步 → 重新登录；
- 同步后 `GET /auth/profile` 的 `personType` 变为 `teacher`，即可建档；
- 前端在教师工作台对 403 展示「当前账号还没有同步到人员数据」的说明，并保留申请记录 / 消息入口。
